# 🧠 Quizzler App

A fun and interactive **True or False Quiz Game** built using **Python** and **Tkinter**.  
It tests your general knowledge, gives instant color feedback, and keeps track of your score as you play.

---

## 🚀 Features
- ✅ Simple and clean user interface (Tkinter)
- 🧩 Interactive true/false quiz format
- 🎨 Visual feedback (green for correct, red for wrong)
- 💯 Real-time score tracking
- 🧠 Modular code structure with `Question`, `QuizBrain`, and `UI` classes

---

## 🖼️ Preview
The interface displays each question with True/False buttons and updates the background color based on your answer.
